# 🎮 UNAD Quest

Mi carrera de **Ingeniería en Inteligencia Artificial y Ciencia de Datos (UNAD)** convertida en un juego.

- **XP = créditos** (150 en total) y niveles cada 20 créditos.
- Malla organizada en mi plan acelerado: 21 créditos por periodo de 16 semanas + intersemestrales 8-03 (9 créditos), inglés homologado.
- Toca un curso para pasarlo de **pendiente → cursando → aprobado**.
- Mantén presionado (o doble clic) para ver sus **prerrequisitos** (amarillo) y lo que **desbloquea** (cian).
- Logros, progreso por línea y cuenta regresiva al grado (dic 2029).
- El progreso se guarda en el navegador; usa **Exportar / Importar** para moverlo entre dispositivos.

> Prerrequisitos interpretados a partir de las líneas de la malla oficial (Resolución 005287 de 2026). Confirmar con consejería antes de matricular.
